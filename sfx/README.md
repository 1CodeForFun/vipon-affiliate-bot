# Hook sound effects

Drop audio files in this folder (`.mp3 .wav .aac .m4a .ogg`) and the reel hook
will pick one at **random** per run, trimmed to the hook length with a short
fade-out. No code change needed — just add files.

If this folder is empty, the hook falls back to one of six **synthesised**
stings chosen at random (`riser_impact`, `whoosh`, `bass_drop`, `sparkle`,
`punch`, `reverse_swell`). Those are generated by ffmpeg at build time, so
there is nothing to license and nothing binary in the repo.

## Why these are not bundled

The reliable CC0 / public-domain libraries — Freesound, Pixabay, Mixkit — all
gate bulk downloads behind API credentials or terms that restrict
redistribution. Pulling audio from anywhere else and committing it here would
put files of unclear licence into the repo, which is a liability on content
that gets published commercially to TikTok, Pinterest, YouTube and Meta.

## If you want real recorded SFX

Download them yourself from a source whose licence you have checked, and drop
them in here. Good options for commercial use:

| Source | Licence | Notes |
|---|---|---|
| [Pixabay Sound Effects](https://pixabay.com/sound-effects/) | Pixabay Content Licence | Free for commercial use, no attribution |
| [Freesound](https://freesound.org/) | Per-file — filter to **CC0** | Check each file; many require attribution |
| [Mixkit SFX](https://mixkit.co/free-sound-effects/) | Mixkit Free Licence | Free for commercial use, no attribution |

Search terms that suit this hook: *whoosh transition*, *impact riser*,
*bass drop*, *notification pop*, *swoosh cinematic*.

Keep them **under ~4 seconds** — anything longer is trimmed to the hook length
(`_HOOK_SECS` in `cf_image_hook.py`, currently 3.5s).
